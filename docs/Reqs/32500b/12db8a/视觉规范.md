# 视觉规范 — 实现随分数递增的难度曲线计算函数

> 所属需求：核心玩法：难度递增曲线

## 整体风格
整体采用扁平化 + 轻像素风（flat pixel）休闲游戏美学：高饱和天空蓝渐变背景与暖黄小鸟、翠绿管道形成强对比，保证高速移动下的可辨识度。HUD 保持低信息密度，仅保留得分/最佳/暂停，避免干扰核心管道穿越玩法。所有文字使用像素字体 + 深色硬描边，按钮统一胶囊圆角 + 底部硬投影，营造轻松、街机、可反复冲分的氛围。

## 组件视觉规范

# 组件视觉规范 — MyFlappy 难度曲线 UI

## 1. HUD 顶栏（常驻浮层）
- 定位：画布顶部，全宽，内边距 `12px`，无背景或半透明黑 `rgba(0,0,0,0.15)` 渐变遮罩（自上而下渐隐）。
- 布局：flex 三区均分，左对齐、居中、右对齐。
- 高度：固定 `64px`，不遮挡主游戏区域。

## 2. 暂停按钮（HUD 左区）
- 尺寸：热区 `44x44px`，icon 本体 `24x24px`。
- 背景：圆形，`radius: pill`，半透明白 `rgba(255,255,255,0.25)`，边框 `2px solid rgba(255,255,255,0.5)`。
- 常态：icon 白色 `#FFFFFF`；按压态：背景变 `rgba(255,255,255,0.4)`，scale 0.92；禁用态：opacity 0.4。

## 3. 得分计数器（HUD 中区）
- 字体：`typography.score` 40px，加粗，白色 `#FFFFFF`。
- 描边：`text_outline` `#3B2F2F`，`shadow.score_text` 硬投影（像素风）。
- 得分变化动画：scale 1.0 → 1.18 → 1.0（约 180ms ease-out）。
- 进入新难度档位时：文字颜色短暂切换为 `tier_glow` `#FFF3B0`，并叠加 `shadow.tier_glow` 光晕，持续 400ms。

## 4. 最佳徽章（HUD 右区）
- 组成：奖杯 icon `16x16px`（金色 `#FFC53D`）+ 数字。
- 容器：胶囊 `radius: pill`，背景 `rgba(255,195,61,0.22)`，边框 `1px solid rgba(255,195,61,0.6)`，内边距 `4px 10px`。
- 数字：`typography.sm` 12px，白色，`weight 700`。

## 5. 难度档位提示（TierNotify，触发态）
- 位置：HUD 下方约 `80px` 居中，飘入后上浮淡出，总时长约 `1.2s`。
- 文案样式：`typography.lg` 20px，`#FFF3B0`，`shadow.tier_glow`。
- 背景：胶囊 `rgba(0,0,0,0.35)`，`radius: pill`，内边距 `6px 16px`，进入时 opacity 0→1。
- 触发条件：speed 每 +40px/s 或 gap / interval 达钳制边界时短暂提示（对应状态机 TierNotify / MaxClamp）。

## 6. 游戏结束面板（GameOver）
- 遮罩：全屏 `overlay` `rgba(0,0,0,0.45)`。
- 面板：居中卡片，背景 `#FFFFFF`，`radius: lg` 20px，`shadow.panel`，内边距 `lg` 24px。
- 标题：`typography.heading` 28px，`text_outline` 深色。
- 得分与最佳：`typography.lg` 20px，主色 `#E8A200` / 绿色 `#4E9A3E`。
- 按钮：主按钮「再来一局」背景 `primary` `#FFC53D`，文字深色，`shadow.button`；次按钮「返回首页」描边样式白底。

## 7. 暂停覆盖层（Paused）
- 遮罩：`overlay`；面板样式同游戏结束面板，标题「暂停」。
- 按钮：继续 / 重新开始，视觉同上述按钮体系。

## 状态色规范
- 危险/碰撞提示：`danger` `#FF6B6B`（碰撞闪烁、生命损失）。
- 警告/即将到上限：`warning` `#FFB020`。
- 成就/跨档：`tier_glow` `#FFF3B0`。
- 常规：`text` `#FFFFFF` + `text_outline` 深色描边保证可读性。
