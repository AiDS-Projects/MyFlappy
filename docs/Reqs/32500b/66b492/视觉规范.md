# 视觉规范 — 集成难度曲线到游戏循环并实现重开重置

> 所属需求：核心玩法：难度递增曲线

## 整体风格
整体采用明亮扁平像素风：高饱和天空蓝背景 + 绿色管道 + 黄色小鸟，配色明快、对比强，符合休闲街机调性。HUD 信息密度极低（仅得分 + 暂停），用大字号像素数字与硬边描边保证远距离可读性。难度曲线为纯逻辑层无独立视觉，其数值变化仅通过管道移动速度与开口间距在游戏层感知，重开面板需明确传达「得分归零、难度重置」的状态反馈。

## 组件视觉规范

# 组件视觉规格

## 全局
- 整体风格：扁平化像素风，高饱和明快配色，硬边阴影（无模糊），按钮带 2px 深色描边与底部 3px 投影营造「可按压」质感。
- 字体：像素字体（Press Start 2P / Pixelify Sans），数字与标题加粗，正文 fallback system-ui。
- 状态反馈：所有可点击元素 hover 时亮度 +8%，active 时向下位移 2px 并消除底部投影。

## 第 3 层 HUD（常驻）

### 暂停按钮（左上角）
- 尺寸：48x48px，圆角 radius.pill。
- 背景：panel_bg 半透明 90%，border 2px panel_border。
- 图标：两条竖线（暂停）轮廓，颜色 text_primary，hover 变 primary。
- 状态：游戏进行中常显；暂停/结束/菜单时隐藏。

### 当前得分（顶部中央）
- 字号：typography.score 48px，颜色 text_on_dark，描边 4px score_outline + shadow.text。
- 位置：水平居中，距顶部 spacing.lg 24px。
- 刷新：得分 +1 时播放 120ms 缩放脉冲（1.0 -> 1.15 -> 1.0），不打断游戏。
- 数值必须随难度曲线得分实时刷新（对应功能需求 1）。

### 本局最高分（右上角，可选）
- 字号：typography.md 18px，颜色 text_on_dark，同描边阴影。
- 仅当存在历史最高分时显示「BEST n」。

## 第 4 层 弹窗 / 面板

### 通用面板
- 背景：panel_bg 100%，border 2px panel_border，圆角 radius.lg 16px，阴影 shadow.lg。
- 内边距：spacing.xl 32px。
- 标题：typography.heading 32px，颜色 text_primary。
- 展开动画：120ms 缩放 0.9 -> 1.0 淡入。

### 主菜单面板
- 标题：游戏名（heading 32px）。
- 开始按钮：primary 背景，白字（text_on_dark），圆角 radius.md，padding md 16px，阴影 shadow.button。

### 暂停面板
- 标题「PAUSED」。
- 继续按钮：primary 主操作；返回菜单按钮：白底 + panel_border 描边（次操作）。
- 背景 overlay rgba(0,0,0,0.45) 遮罩；难度值冻结（对应边界条件：暂停期间难度冻结不增长）。

### 游戏结束面板（重开核心）
- 背景：overlay 遮罩上居中面板。
- 内容自上而下：本局得分（score 48px，accent 色）、最高分（md 18px，text_muted）。
- 「再来一局」按钮（主操作）：primary 背景白字，圆角 radius.md，padding 16px 32px，阴影 shadow.button；hover 亮度 +8%；active 下移 2px。
- 「返回菜单」按钮（次操作）：白底 + panel_border 描边，text_primary 文字。
- 重开触发后：面板 150ms 淡出，得分显示归 0，难度值恢复初始（对应功能需求 4、验收标准：重开第一帧得分=0、三难度值=初始值）。

## 第 2 层 游戏层（难度输出仅驱动此层，无独立 UI）

### 管道组（成对上下管道）
- 主体：pipe 色，左缘加 8px 高光条 pipe_light，右缘 4px 暗部 pipe_dark，营造圆柱体积。
- 开口间距：由难度曲线「开口间距」实时决定，视觉上表现为上下管道间隙高度。
- 水平左移速度：由难度曲线「移动速度」实时决定（越快越紧张）。

### 小鸟（玩家）
- 主体：bird_body 黄，翅膀 bird_wing，喙 bird_beak，眼睛白底黑瞳。
- 受重力/点击上浮；死亡时播放旋转下坠（红眼 + 上翻）。

### 地面
- 顶部 4px 草绿色 ground 条 + 下方 ground_dark 纹理；随移动速度同速滚动（装饰）。

### 得分判定线
- 不可见通过线，位于每组管道中央，玩家穿过 +1 分，无视觉元素。
## 精灵图规格
bird_idle: 3 帧循环动画（翅膀上/中/下），单帧 34x24px，总 102x24px 精灵条，帧率 8fps
ground_strip: 无缝平铺条 336x112px，横向滚动，滚动速度绑定难度曲线「移动速度」
pipe_up / pipe_down: 各 52x320px，含左高光条 + 右暗部，成对组合，开口间距由难度曲线「开口间距」驱动
sky_bg: 288x512px 可平铺背景，静态，不随难度变化

动画时长 / 帧数补充：小鸟死亡旋转下坠帧可由 bird_idle 旋转变换实现，无需新增帧。
