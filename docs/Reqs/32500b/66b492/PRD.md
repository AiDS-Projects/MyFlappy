# PRD — 集成难度曲线到游戏循环并实现重开重置

> 所属需求：核心玩法：难度递增曲线

## 用户故事
As a 玩家，I want 游戏主循环随得分实时驱动管道移动与生成难度，So that 我能感受到分数越高越难打的紧张感，并在死亡重开后从初始难度重新冲击纪录。

## 功能需求
1. 游戏主循环（update/每帧）读取当前得分，调用难度曲线计算函数，实时获取当前管道移动速度、开口间距、生成间隔三个难度值。\n2. 管道生成器使用实时「生成间隔」值决定下一次管道生成的时机；新生成管道的开口间距使用实时「开口间距」值。\n3. 所有已生成与后续生成的管道使用实时「移动速度」值进行水平移动。\n4. 玩家死亡后触发重开时（[假设] 点击「再来一局」按钮或按空格/重试键），得分归零，难度曲线计算函数重置到初始状态，速度/间距/间隔恢复为配置初始值。\n5. 难度曲线所需全部参数（初始速度、速度上限、初始间距、最小间距下限、初始间隔、最小间隔下限、递增/递减系数）统一从配置常量表读取，游戏循环内不出现硬编码魔法数字。\n6. 难度计算保持确定性：相同得分下计算出的难度值完全一致，不引入随机波动。

## 验收标准
- [ ] 得分为 0 时，管道移动速度 = 配置初始速度值，开口间距 = 配置初始间距值，生成间隔 = 配置初始间隔值（三者与配置常量表一致）。\n- [ ] 得分每增加 1 分，移动速度按曲线函数单调递增；任意相邻两分的速度增量 ≤ 配置的最大单分增量（无跳变）。\n- [ ] 移动速度在任意得分下 ≤ 配置的速度上限值。\n- [ ] 开口间距随得分单调递减，且在任意得分下 ≥ 配置的最小间距下限值。\n- [ ] 生成间隔随得分单调缩短，且在任意得分下 ≥ 配置的最小间隔下限值。\n- [ ] 从得分 0 到得分 100 区间内，难度值变化为平滑连续递增/递减，不存在反向跳变点（速度不回退、间距不回增、间隔不回增）。\n- [ ] 玩家死亡后触发重开，重开后的第一帧：得分 = 0，移动速度/开口间距/生成间隔均等于初始值（与第 0 分状态一致）。\n- [ ] 连续进行两局，达到相同得分时，三项目难度值逐项完全相等（确定性验证，误差 = 0）。\n- [ ] 在速度上限与最小间距下限同时生效的极限得分下，游戏仍存在可通过的开口路径（理论可通过，无必死配置）。

## 边界条件（不做的事）
不包含：多种障碍物（移动管道、旋转门）。\n不包含：道具系统（护盾、慢速）。\n不包含：难度参数的可视化调参界面，仅提供配置常量表。\n不包含：最高分/最高难度持久化与排行榜功能。\n不包含：暂停/继续时的难度变化逻辑；若已有暂停功能，暂停期间难度值保持冻结不增长。\n不包含：难度曲线的数值调优与最终平衡数值的确定（仅做接入与重置，参数值以配置表为准）。
