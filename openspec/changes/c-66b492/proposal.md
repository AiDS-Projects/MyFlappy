# 集成难度曲线到游戏循环并实现重开重置

## Why

难度曲线纯函数 `calculateDifficulty(score)` 已就绪（上一变更 c-12db8a），但尚未接入游戏主循环：管道生成与移动仍无法消费实时难度值，玩家体验不到「分数越高越难」的紧张感；且死亡重开后难度状态没有归零机制，无法从初始难度重新冲击纪录。本变更补齐游戏循环侧的难度消费与生命周期重置。

## What Changes

- 新增游戏主循环难度状态：当前得分与当前难度三元组（`speed` / `gap` / `interval`）由循环统一持有，每帧（update）读取当前得分并调用 `calculateDifficulty` 实时刷新。
- 管道生成器消费实时 `interval` 决定下一组管道生成时机；新生成管道的开口间距使用实时 `gap`。
- 所有已生成与后续生成管道的水平移动统一使用实时 `speed`。
- 玩家死亡后触发重开：得分归零，难度重置为初始值（与 score=0 状态逐字段一致），重开第一帧即生效。
- 全部难度参数从配置常量表（`DIFFICULTY_CONFIG`）读取，游戏循环内不出现硬编码魔法数字。
- 难度计算保持确定性：相同得分下输出逐字段完全一致，不引入随机波动。

## Capabilities

### New Capabilities

- `game-difficulty-loop`: 游戏主循环实时消费难度曲线——按当前得分刷新速度 / 开口间距 / 生成间隔，并驱动管道生成与移动；确定性、无魔法数字、任意得分不越界。
- `game-restart`: 玩家死亡后触发重开，得分归零、难度三元组重置为初始值，重开第一帧即恢复到与第 0 分一致的状态。

### Modified Capabilities

（无 —— 难度曲线纯函数 `difficulty-curve` 的契约不变，本变更仅在其下游接入消费。）

## Impact

- 代码：新增游戏循环 / 管道生成 / 管道移动 / 得分与游戏状态模块（如 `src/game/` 下），并通过 barrel 导出；`calculateDifficulty` 与 `DIFFICULTY_CONFIG` 已由 `src/index.ts` 导出，直接消费。
- 类型：新增游戏状态类型（得分、游戏阶段、当前难度三元组）。
- 调用方：管道生成器与移动逻辑改为消费实时难度值，替代散落的硬编码数值。
- 依赖：无新增第三方依赖，纯 TypeScript；新增单元测试覆盖集成与重置验收点。
